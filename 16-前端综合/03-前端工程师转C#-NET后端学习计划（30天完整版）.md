## 一、学习目标与预期结果

> 适用人群：前端工程师，后端零基础，希望在有限下班时间内系统转向 C#/.NET 后端开发。

**总目标（30天）**：
从 0 到 1 完成一个可运行、可演示、可继续迭代的 ASP.NET Core Web API 项目，掌握从语言基础、数据库、ORM 到认证授权与接口规范化的完整后端开发路径。

**完成后你应达到的结果**：

- 能独立创建并运行 C#/.NET Web API 项目
- 能使用 SQL 设计基础表结构并完成常见查询
- 能使用 EF Core 完成 CRUD、分页、条件查询
- 能实现参数校验、统一异常处理、日志记录、Swagger 文档
- 能实现 JWT 登录鉴权与基于角色/策略的授权控制
- 能完成一个小型后端项目并掌握基础部署流程

## 二、学习时间假设与节奏

### 1）时间假设（按你的实际情况）

- 工作日：**晚 6:45 下班后学习**
- 周一到周五：每天 **1.5~2 小时**
- 周末：每天 **3~5 小时**
- 可持续节奏：每天都有小产出，周末做整合

### 2）推荐每日模板

| 场景 | 时间分配 | 说明 |
|---|---:|---|
| 工作日 | 20min 复盘 + 40min 学习 + 40min 编码 + 10min 总结 | 保证“学-练-记”闭环 |
| 周末 | 60min 复盘 + 120~180min 项目实战 + 30min 梳理问题 | 把零散知识串成系统能力 |

### 3）每周节奏建议

- **周一**：新概念输入（重点理解）
- **周二**：跟练（照着写）
- **周三**：独立小练习（脱离教程）
- **周四**：补坑+查资料（理解薄弱点）
- **周五**：周复盘（整理笔记、提交一版可运行代码）
- **周六**：模块开发（本周核心功能）
- **周日**：联调、重构、预习下周

## 三、分阶段学习路线（8个阶段）

### 阶段 1：C# 语言基础（Day 1~5）

**目标**：掌握语法与基础流程控制，能写控制台小程序。

- 核心：变量、类型、字符串、条件、循环、集合、方法
- 输出：控制台练习代码 + 基础语法笔记

### 阶段 2：C# 面向对象（Day 6~9）

**目标**：理解 class/interface/abstract 的使用场景。

- 核心：封装、继承、多态、构造函数、访问修饰符、异常处理
- 输出：学生/商品管理类模型 + OOP 小练习

### 阶段 3：.NET / ASP.NET Core Web API 基础（Day 10~14）

**目标**：能创建并运行 Web API，理解请求管道。

- 核心：项目结构、Program.cs、Controller、Route、DI、Middleware
- 输出：基础 Users API（内存版）

### 阶段 4：SQL / 数据库基础（Day 15~17）

**目标**：能设计基础表并写常见 SQL。

- 核心：SELECT/INSERT/UPDATE/DELETE、WHERE、JOIN、GROUP BY、索引基础
- 输出：用户/任务/标签三表设计 + SQL 练习脚本

### 阶段 5：EF Core 与 CRUD（Day 18~22）

**目标**：打通 API + 数据库，完成可用 CRUD。

- 核心：DbContext、DbSet、Migration、异步查询、分页筛选
- 输出：数据库驱动的 Users/Tasks CRUD API

### 阶段 6：API 规范化（验证/日志/异常/Swagger）（Day 23~25）

**目标**：把“能跑”升级为“可维护”。

- 核心：DTO、参数校验、统一返回、全局异常、日志、Swagger 注释
- 输出：规范化 API 文档与错误处理链路

### 阶段 7：认证与授权（JWT + Roles/Policies）（Day 26~27）

**目标**：实现登录鉴权与权限控制。

- 核心：注册/登录、JWT、[Authorize]、角色与策略授权
- 输出：带权限控制的受保护接口

### 阶段 8：Capstone 项目与部署基础（Day 28~30）

**目标**：完成一个完整后端作品并可演示。

- 核心：项目整合、测试、README、环境配置、基础部署
- 输出：可运行项目 + 接口文档 + 演示说明

## 五、项目驱动学习法（强烈建议）

只看教程很容易“以为会了”，建议从 Day 10 开始始终围绕一个小项目推进。

### 推荐 Capstone 题目（选 1）

1. **任务管理系统 API（推荐）**
   - 模块：用户、任务、标签、任务状态流转
2. **博客后台 API**
   - 模块：文章、分类、标签、评论、审核
3. **轻量电商后台 API**
   - 模块：用户、商品、订单、库存

### 项目最低功能要求（验收线）

- [ ] 用户注册/登录（JWT）
- [ ] 至少 2 个业务实体 CRUD
- [ ] 分页 + 条件筛选 + 排序
- [ ] 参数校验 + 统一错误处理
- [ ] Swagger 文档可直接调试
- [ ] 基础角色权限（如 Admin/User）
- [ ] README 含运行步骤与接口说明
